# Portfolio Specs

This folder breaks the brief into build-ready specs for the Next.js portfolio.

Use these files in this order:

1. `01-foundation.md`
2. `02-pages-and-routes.md`
3. `03-design-system.md`
4. `04-content-model.md`
5. `05-technical-implementation.md`
6. `06-delivery-and-qa.md`
7. `07-open-questions.md`

What each file is for:

- `01-foundation.md`: project intent, audience, locked decisions, and non-goals
- `02-pages-and-routes.md`: route-level page requirements, section order, and component needs
- `03-design-system.md`: visual system, layout, typography, imagery, motion, and interaction rules
- `04-content-model.md`: content inventory, placeholder handling, and MDX/content structure
- `05-technical-implementation.md`: Next.js architecture, folders, data flow, SEO, and asset strategy
- `06-delivery-and-qa.md`: implementation phases, acceptance checks, and ship checklist
- `07-open-questions.md`: missing inputs that must be answered before final content can ship

This spec set is meant to reduce drift while building. The brief remains the source of truth when wording conflicts.
