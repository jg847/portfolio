# Phase 04 Assets And Polish

## Goal
Replace placeholder media where available, tighten the visual system, and make the site feel composed and finished without breaking the restraint of the brief.

## In scope
- screenshots and demo media
- favicon
- final spacing and typography adjustments
- image treatment and framing consistency
- CTA/copy cleanup against banned words
- placeholder replacement where real values exist

## Out of scope
- broad structural rewrites of the app
- new features not already in the specs
- analytics scope expansion

## Inputs
- `docs/_specs/03-design-system.md`
- `docs/_specs/04-content-model.md`
- `docs/_specs/06-delivery-and-qa.md`
- `docs/_specs/07-open-questions.md`

## Implementation checklist

### Media replacement
- add final product screenshots for each project if available
- add voice consultant demo media
- create and wire the simple geometric favicon
- add optional process artifacts only where they strengthen proof

### Placeholder replacement
- replace placeholders only with real provided values
- keep exact placeholder tags for anything still unknown
- do not invent testimonial copy, numbers, or URLs

### Visual polish
- tune spacing between major page bands
- tune image crop/framing consistency
- tune type rhythm and metadata treatment
- keep accent usage restrained
- check that asymmetry still supports fast scanning

### Copy and CTA cleanup
- scan for banned words and generic portfolio language
- verify all button labels use approved verb phrases
- ensure the README plan is still aligned with the shipped state

## Deliverables
- polished screenshots/demo media in place where available
- favicon wired
- refined layout rhythm and image presentation
- placeholder usage reduced where real data exists, preserved where it does not

## Validation during this phase
- screenshots and media load correctly
- no autoplay media appears
- no banned visual patterns are introduced during polish
- no invented content has been added while replacing placeholders
- exact placeholder tags remain in place for any values still missing after polish
- proof remains adjacent after final media insertion

## Exit criteria
- the site feels intentional and finished within the locked aesthetic
- media is consistent across home and case-study pages
- unresolved data is clearly represented with placeholders rather than hidden or fabricated
- the site is ready for a strict validation pass
